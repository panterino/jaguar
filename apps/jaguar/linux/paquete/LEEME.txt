Jaguar Code para Linux (64 bits)

Para abrirlo:
  ./jaguar

Para agregarlo al menú de aplicaciones:
  ./instalar.sh

Necesita GTK 3, que ya trae casi cualquier escritorio (GNOME, KDE, Xfce...).
Para abrir archivos con el selector de archivos conviene tener zenity o
kdialog instalado.

Las clases y la comunidad necesitan conexión; todo lo demás funciona sin
internet.

https://jaguarcode.org
