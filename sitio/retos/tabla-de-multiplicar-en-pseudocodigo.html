Algoritmo para mostrar la tabla de multiplicar

El ciclo Para cuenta por ti: una variable que va de 1 a 10 y repite lo mismo en cada vuelta.

El problema y su planteamiento

Lee un número y muestra su tabla del 1 al 10.

Con 3, muestra:
3 x 1 = 3
3 x 2 = 6
…
3 x 10 = 30

Planteamiento: entrada, proceso y salida
EntradaProcesoSalida
Un número.Repetir 10 veces, multiplicando el número por 1, por 2… por 10.Diez renglones con la forma 3 x 1 = 3.

Diagrama de flujo

Así se dibuja el algoritmo: el óvalo marca el inicio y el fin, el paralelogramo es una entrada o una salida, el rectángulo es un proceso y el rombo es una decisión.

Pseudocódigo

Esta es una solución. Léela línea por línea con el diagrama al lado y compara con lo que tú escribirías.

Algoritmo tabla_de_multiplicar
    Leer n
    Para i <- 1 Hasta 10 Hacer
        Escribir n, " x ", i, " = ", n * i
    FinPara
FinAlgoritmo

Con estas entradas, el programa debe mostrar exactamente esa salida.

Cómo pensarlo

Sabes exactamente cuántas veces repetir: diez. Para esos casos está el ciclo Para: Para i <- 1 Hasta 10 Hacer. La variable i vale 1 en la primera vuelta, 2 en la segunda, y así hasta 10.

Dentro del ciclo, un solo Escribir arma cada renglón: el número, el texto " x ", el valor de i, el texto " = " y el resultado de multiplicar. Los textos van entre comillas y se separan con comas.

FinPara cierra el ciclo. No hace falta sumar a i ni revisar nada: el ciclo Para se encarga de contar y de parar.

Errores comunes

  • Poner el Escribir fuera del ciclo: mostraría un solo renglón.
  • Olvidar los espacios dentro de las comillas: " x " con espacios evita que salga 3x1=3.
  • Modificar i dentro del ciclo: Para ya la cambia sola en cada vuelta.

El mismo programa en Python

Si más adelante pasas a Python, así se ve la misma lógica. Cambian las palabras (print, input, if) y los bloques se marcan con sangría en lugar de FinSi o FinPara.

# Algoritmo tabla_de_multiplicar
n = float(input())
for i in range(1, 11):
    print(n, " x ", i, " = ", n * i, sep="")

Preguntas frecuentes

¿Cuándo se usa el ciclo Para?

Cuando sabes cuántas veces repetir, como diez vueltas para una tabla. Si no lo sabes, se usa Mientras o Repetir.

¿Puedo contar de dos en dos o hacia atrás?

Sí, con Con Paso: Para i <- 10 Hasta 1 Con Paso -1 cuenta hacia atrás. Si el inicio es mayor que el final y no pones paso, Jaguar cuenta hacia atrás solo.
