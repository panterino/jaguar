Se esperaba '[' con el tamaño del arreglo

Para crear un arreglo con Dimension hay que decir cuántas casillas tiene, entre corchetes, justo después del nombre.

En esta página
  1. Qué significa
  2. Ejemplos y cómo arreglarlos
  3. Por qué aparece
  4. Preguntas frecuentes

Qué significa

Error de escritura en la línea 2
Se esperaba '[' con el tamaño del arreglo, por ejemplo: Dimension v[10].

Dimension crea un arreglo: una variable con varias casillas numeradas. Para eso necesita dos cosas, el nombre y el tamaño, y el tamaño va entre corchetes: Dimension calificaciones[30]. Para una matriz, se ponen las dos medidas separadas por coma: Dimension tabla[3, 4].

Si después del nombre no hay un corchete, Jaguar no sabe de qué tamaño hacer el arreglo y te muestra cómo se escribe, usando el nombre de tu arreglo.

Ejemplos y cómo arreglarlos

El tamaño entre paréntesis

Algoritmo lista
    Dimension v(5)
FinAlgoritmo

Error de escritura en la línea 2
Se esperaba '[' con el tamaño del arreglo, por ejemplo: Dimension v[10].

En Dimension, el tamaño siempre va entre corchetes:

Algoritmo lista
    Dimension v[5]
    v[5] <- 1
    Escribir v[5]
FinAlgoritmo

Sin tamaño

Algoritmo lista
    Dimension nombres
FinAlgoritmo

Error de escritura en la línea 2
Se esperaba '[' con el tamaño del arreglo, por ejemplo: Dimension nombres[10].

Así queda arreglado:

Algoritmo lista
    Dimension nombres[3]
    nombres[1] <- "Ana"
    Escribir nombres[1]
FinAlgoritmo

Por qué aparece

  • Usar paréntesis en lugar de corchetes al crear el arreglo.
  • Olvidar el tamaño.
  • Querer crear el arreglo sin saber cuántos datos habrá. El tamaño puede ser una variable que ya tenga valor: Leer n y luego Dimension v[n].

Preguntas frecuentes

¿El tamaño puede ser una variable?

Sí, mientras la variable ya tenga un valor cuando se ejecuta Dimension. Por ejemplo: Leer n y después Dimension v[n].

¿Desde qué número empiezan las posiciones?

En PSeInt (perfil flexible) y en Jaguar, desde 1. Un arreglo creado con Dimension v[5] tiene las posiciones 1 a 5.
