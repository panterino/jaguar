Errores en pseudocódigo

Jaguar puede detenerse en dos momentos. Un error de escritura aparece cuando no puede leer el programa; uno al ejecutar, cuando el programa se entiende pero algo falla mientras corre. Aquí está cada mensaje explicado con calma, con un ejemplo del error y cómo se arregla.

«Encontré …, pero antes falta …»: un bloque sin cerrar

Este error aparece cuando un bloque, como un Si, un Para o un Mientras, no se cerró antes de que llegara el cierre de otro bloque. Casi siempre falta un FinSi, un FinPara o un FinMientras.

Falta FinAlgoritmo, FinSi o FinPara para cerrar un bloque

Jaguar llegó al final de tu programa y un bloque seguía abierto. El mensaje dice qué cierre falta y en qué línea empieza el bloque que lo necesita.

Falta la comilla que cierra este texto

Un texto empieza con comillas y debe terminar con comillas en la misma línea. Este error aparece cuando abriste las comillas y la línea se acabó sin cerrarlas.

Falta poner el texto entre comillas

Jaguar encontró varias palabras sueltas después de Escribir. Seguramente querías mostrar un texto, y los textos van entre comillas.

No entiendo la instrucción

Cada línea de un programa debe empezar con una instrucción que Jaguar conozca, como Escribir, Leer, Si o una asignación. Este error aparece cuando la primera palabra de la línea no es ninguna de ellas.

Sobra algo al final de la instrucción

Jaguar terminó de leer una instrucción completa y todavía quedaba algo en la línea. Casi siempre falta una coma entre dos valores o un operador entre dos números.

Se esperaba un valor

En ese lugar de la instrucción debía ir un valor, como un número, un texto, una variable o una operación, y Jaguar encontró otra cosa o nada.

Se esperaba ')' para cerrar el paréntesis

Abriste un paréntesis o un corchete y la línea se terminó, o apareció otra cosa, antes de cerrarlo.

Se esperaba '<-' para asignar un valor

Jaguar entendió que querías guardar un valor en una variable o en una casilla de un arreglo, pero no encontró la flecha <- que hace la asignación.

Es una palabra reservada y no puede ser un nombre

Usaste como nombre de variable una palabra que el pseudocódigo ya usa para otra cosa, como Si, Para, Y u O. Hay que elegir otro nombre.

Errores al escribir un ciclo Para

El ciclo Para tiene una forma fija: Para variable <- inicio Hasta fin Con Paso n Hacer. Estos errores aparecen cuando falta o está mal escrita una de sus partes.

Errores al usar Definir

Definir declara de qué tipo es una variable y siempre se escribe igual: Definir nombre Como Tipo. Estos errores aparecen cuando falta Como, el tipo no existe o el nombre no es válido.

Se esperaba '[' con el tamaño del arreglo

Para crear un arreglo con Dimension hay que decir cuántas casillas tiene, entre corchetes, justo después del nombre.

Dentro de Segun, cada opción empieza con un valor seguido de ':'

Cada opción de un Segun se escribe con el valor, dos puntos y lo que hay que hacer. Este error aparece cuando una opción no tiene esa forma, casi siempre porque faltan los dos puntos.

Errores al usar funciones y subprocesos

Al usar una función hay que llamarla con su nombre exacto y con el número de valores que espera. Y solo las funciones que devuelven un resultado pueden usarse dentro de una operación.

El código debe ir dentro de Algoritmo … FinAlgoritmo

Todo programa tiene un bloque principal que empieza con Algoritmo y termina con FinAlgoritmo, y las instrucciones van dentro de él. Afuera solo pueden ir funciones.

No reconozco el carácter

Fuera de los textos entre comillas, un programa solo puede tener letras, números y ciertos símbolos. Este error aparece cuando hay un símbolo que el pseudocódigo no usa.

Se esperaba 'Segundos' o 'Milisegundos' en Esperar

La instrucción Esperar pausa el programa. Necesita la cantidad y la unidad de tiempo: Esperar 2 Segundos o Esperar 500 Milisegundos.

«No encuentro la variable» y «todavía no tiene valor»

Estos errores aparecen cuando el programa usa una variable que todavía no existe o que existe pero aún no guarda nada. Se arreglan dándole un valor antes de usarla, con una asignación o con Leer.

«La posición … está fuera del arreglo»

Este error aparece cuando el programa usa una posición que el arreglo no tiene. En Jaguar las posiciones empiezan en 1 y terminan en el tamaño con el que creaste el arreglo.

Un valor que no corresponde al tipo de la variable

Estos errores aparecen cuando una variable con tipo (Entero, Real, Texto o Lógico) recibe un valor de otro tipo: un decimal en un Entero, un número en un Texto o letras donde se esperaba un número.

«Pidió un dato con Leer, pero ya no hay datos de entrada»

Este error aparece cuando el programa tiene más instrucciones Leer que datos de entrada. Pasa en las pruebas, en la prueba de escritorio y en los ejercicios con casos de prueba.

«El programa se detuvo porque llevaba demasiados pasos»

Este error aparece cuando un ciclo nunca termina, casi siempre porque dentro del ciclo no cambia nada que haga falsa la condición. Jaguar lo detiene para que el programa no se quede trabajando para siempre.

«No se puede dividir entre cero»

Este error aparece cuando una división, o un MOD, tiene un divisor que vale 0 al llegar a esa línea. Se evita preguntando antes si el divisor es distinto de cero.

«La condición debe ser Verdadero o Falso»

Este error aparece cuando después de Si, Mientras o Hasta Que va un valor que no es una comparación, por ejemplo solo un número o un texto. Una condición tiene que dar Verdadero o Falso.

Una operación mezcla texto y números

Estos errores aparecen cuando una cuenta o una comparación mezcla un texto con un número. Se arreglan convirtiendo el texto a número, o comparando cosas del mismo tipo.

Errores de funciones al ejecutar: recursión sin fin y funciones sin valor

Estos errores aparecen cuando una función se llama a sí misma sin parar (le falta el caso base) o cuando una función termina sin haberle dado valor a lo que debía devolver.

Un valor no válido en una función, un arreglo o un ciclo

Estos errores aparecen cuando una función matemática recibe un valor para el que no existe resultado, o cuando un arreglo o un ciclo reciben un tamaño o un paso imposible.

Practica esto en Jaguar Code

Escribe pseudocódigo, mira su diagrama y haz la prueba de escritorio desde el celular. Gratis, sin anuncios y sin cuenta.
