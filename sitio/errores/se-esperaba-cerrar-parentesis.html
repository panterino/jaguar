Se esperaba ')' para cerrar el paréntesis

Abriste un paréntesis o un corchete y la línea se terminó, o apareció otra cosa, antes de cerrarlo.

En esta página
  1. Qué significa
  2. Ejemplos y cómo arreglarlos
  3. Por qué aparece
  4. Cómo evitarlo
  5. Preguntas frecuentes

Qué significa

Error de escritura en la línea 2
Se esperaba ')' para cerrar el paréntesis, pero encontré el fin de la línea.

Los paréntesis y los corchetes van en pareja: cada ( necesita su ) y cada [ su ]. Jaguar avisa en cuanto encuentra algo que no debería estar antes del cierre, o cuando la línea se acaba.

El mensaje dice para qué era el paréntesis que falta cerrar:

  • «para cerrar el paréntesis»: un paréntesis de agrupación en una operación, como (a + b) / 2.
  • «para cerrar la llamada a …»: los paréntesis de una función, como Raiz(16).
  • «para cerrar el índice»: el corchete de un arreglo, como v[3].

Ejemplos y cómo arreglarlos

Un paréntesis de agrupación

Algoritmo promedio
    p <- (8 + 9 + 10 / 3
    Escribir p
FinAlgoritmo

Error de escritura en la línea 2
Se esperaba ')' para cerrar el paréntesis, pero encontré el fin de la línea.

Ojo con dónde va el cierre: lo que quede dentro del paréntesis se calcula primero. Para un promedio, la suma completa va adentro:

Algoritmo promedio
    p <- (8 + 9 + 10) / 3
    Escribir p
FinAlgoritmo

La llamada a una función

Algoritmo raiz
    Escribir Raiz(81
FinAlgoritmo

Error de escritura en la línea 2
Se esperaba ')' para cerrar la llamada a Raiz, pero encontré el fin de la línea.

Así queda arreglado:

Algoritmo raiz
    Escribir Raiz(81)
FinAlgoritmo

El corchete de un arreglo

Algoritmo arreglo
    Dimension v[3
FinAlgoritmo

Error de escritura en la línea 2
Se esperaba ']' para cerrar el índice, pero encontré el fin de la línea.

Así queda arreglado:

Algoritmo arreglo
    Dimension v[3]
    v[1] <- 7
    Escribir v[1]
FinAlgoritmo

Por qué aparece

  • Se olvidó el cierre, sobre todo con varios paréntesis anidados: Raiz((a + b).
  • Se cerró con el símbolo equivocado: (a + b].
  • Falta una coma entre los valores de una función, y Jaguar encuentra el segundo valor donde esperaba el cierre.

Cómo evitarlo

Cuenta los paréntesis: debe haber tantos que abren como que cierran. Igual que con las comillas, escribir la pareja () y luego rellenar el contenido evita olvidos.

Preguntas frecuentes

¿Puedo usar corchetes para agrupar operaciones?

No. Los corchetes son para los arreglos (v[3]). Para agrupar operaciones se usan solo paréntesis, aunque haya varios niveles: ((a + b) * c) / 2.

¿Se puede usar v(3) en lugar de v[3]?

Sí, si el arreglo se creó con Dimension: Jaguar entiende v(3) como en DFD. Pero la forma de PSeInt, v[3], es la más común.
