Un valor no válido en una función, un arreglo o un ciclo

Estos errores aparecen cuando una función matemática recibe un valor para el que no existe resultado, o cuando un arreglo o un ciclo reciben un tamaño o un paso imposible.

Qué significa

Error al ejecutar en la línea 2
No se puede sacar la raíz cuadrada de un número negativo (-4).

Algunas operaciones no tienen resultado para ciertos valores: no hay raíz cuadrada (real) de un número negativo, ni logaritmo de cero, ni arreglos de cero casillas, ni ciclos que avancen de cero en cero. En esos casos Jaguar se detiene y te dice qué valor no sirve, porque casi siempre es un dato que llegó de una cuenta o de la persona.

Ejemplos y cómo arreglarlos

La raíz de un negativo

Algoritmo a
    Escribir Raiz(-4)
FinAlgoritmo

Revisa que el número no sea negativo antes de sacar la raíz:

Algoritmo a
    Leer x
    Si x >= 0 Entonces
        Escribir Raiz(x)
    SiNo
        Escribir "No hay raíz de un negativo"
    FinSi
FinAlgoritmo

Logaritmo de cero

Algoritmo a
    Escribir Ln(0)
FinAlgoritmo

Un arreglo sin casillas

Algoritmo a
    Dimension v[0]
FinAlgoritmo

Si el tamaño lo escribe la persona, revisa que sea al menos 1 antes de crear el arreglo.

Un Para que no avanza

Algoritmo a
    Para i <- 1 Hasta 5 Con Paso 0 Hacer
        Escribir i
    FinPara
FinAlgoritmo

El paso es lo que suma el ciclo en cada vuelta. Con 0 no avanzaría nunca, así que debe ser distinto de cero, positivo para subir y negativo para bajar:

Algoritmo a
    Para i <- 1 Hasta 5 Con Paso 2 Hacer
        Escribir i
    FinPara
FinAlgoritmo

Por qué aparece

  • El número viene de un dato de la persona o de un cálculo previo que dio un valor inesperado.
  • Una resta deja un valor negativo donde se esperaba positivo.
  • El tamaño o el paso se calculan con una variable que vale cero.

Cómo evitarlo

Valida los datos antes de usarlos con un Si: que el número sea mayor o igual que cero, mayor que cero, o distinto de cero según la función. Es el mismo hábito que para la división entre cero.

Preguntas frecuentes

¿Hay raíz cuadrada de un número negativo?

En matemáticas existen los números complejos, pero Jaguar trabaja con números reales, y ahí no existe. Por eso lo avisa.

¿Puede el paso del Para ser negativo?

Sí. Un paso negativo hace que el ciclo cuente hacia atrás: Para i <- 5 Hasta 1 Con Paso -1.
