Cómo hacer un diagrama de flujo

Un diagrama de flujo representa un algoritmo con figuras unidas por flechas. Para hacerlo: marca el inicio, dibuja cada paso con su figura, usa un rombo en cada decisión y cierra con el fin.

Los símbolos principales

Figuras del diagrama de flujo
FiguraNombreSe usa para
ÓvaloInicio y fin
ParalelogramoEntrada y salida de datos (Leer, Escribir)
RectánguloProceso: cálculos y asignaciones
RomboDecisión: una pregunta con dos salidas, Sí y No
FlechaIndica el orden en que se sigue el diagrama

Los libros de cada materia pueden usar variaciones (por ejemplo, otra figura para repetir), pero estas cinco bastan para casi todos los ejercicios de un primer curso.

Para ver el diagrama de un algoritmo ya escrito, usa el generador de diagramas de flujo online: pegas el pseudocódigo y lo descargas como imagen.

Cómo dibujarlo, paso a paso

  1. Entiende el problema. Escríbelo con tus palabras y decide qué entra y qué debe salir.
  2. Piensa los pasos en una lista corta, en el orden en que ocurren.
  3. Dibuja el inicio con un óvalo.
  4. Agrega cada paso con su figura: paralelogramo para leer y escribir, rectángulo para calcular.
  5. Usa un rombo cuando haya una decisión. Escribe la pregunta dentro y rotula las dos salidas con Sí y No.
  6. Une todo con flechas, de arriba hacia abajo, y junta las ramas cuando terminen.
  7. Cierra con un óvalo de fin y revisa que todo camino llegue a él.

Ejemplo: promedio de dos calificaciones

El problema: leer dos calificaciones, calcular el promedio y decir si el alumno pasó (promedio de 6 o más).

El mismo algoritmo en pseudocódigo, figura por figura:

Algoritmo promedio
    Leer a, b
    p <- (a + b) / 2
    Si p >= 6 Entonces
        Escribir "Pasaste con ", p
    SiNo
        Escribir "Casi, sacaste ", p
    FinSi
FinAlgoritmo

Fíjate que cada línea del programa tiene su figura: Leer es el paralelogramo de entrada, la asignación es el rectángulo, el Si es el rombo y cada Escribir es un paralelogramo de salida.

Cómo se dibuja una repetición

Un ciclo se dibuja con un rombo y una flecha que regresa: mientras la pregunta se cumple (Sí), el flujo vuelve a la parte de arriba; cuando no (No), sigue hacia adelante. Por eso el rombo de un ciclo tiene siempre una flecha que sube.

Algoritmo cuenta
    n <- 3
    Mientras n > 0 Hacer
        Escribir n
        n <- n - 1
    FinMientras
    Escribir "¡Despegue!"
FinAlgoritmo

Reglas para que se entienda

  • Un solo inicio y, normalmente, un solo fin.
  • El flujo va de arriba hacia abajo y de izquierda a derecha.
  • Cada rombo tiene dos salidas rotuladas.
  • Dentro de cada figura, texto corto: Leer a, b y no «aquí el programa le pide al usuario dos números».
  • Evita que las flechas se crucen; si pasa, reacomoda las figuras.

Errores comunes

  • Un rombo con una sola salida, o con salidas sin rotular.
  • Una figura sin flecha de salida (el diagrama «se queda colgado»).
  • Usar un rectángulo para leer datos en lugar del paralelogramo.
  • Olvidar la flecha que regresa en un ciclo, de modo que solo se ejecuta una vez.

Preguntas frecuentes

¿Qué programa uso para hacer un diagrama de flujo?

Puedes dibujarlo a mano o con cualquier programa de dibujo. Con Jaguar lo armas con las figuras y la app escribe el pseudocódigo, o escribes el pseudocódigo y te muestra el diagrama.

¿Cuál es la diferencia entre un diagrama de flujo y el pseudocódigo?

Dicen lo mismo con otra forma. El diagrama es visual y deja ver las decisiones y los ciclos de un vistazo; el pseudocódigo es texto y se acerca más a un programa real.

¿Todos los diagramas llevan las mismas figuras?

Las más importantes son las mismas en casi todos lados: óvalo, paralelogramo, rectángulo, rombo y flechas. Algunas materias agregan figuras para ciclos o conectores; sigue las de tu profesor.
