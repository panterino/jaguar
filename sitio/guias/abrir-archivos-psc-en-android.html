Cómo abrir un archivo .psc en el celular

Un archivo .psc es un texto con un algoritmo en pseudocódigo. Para abrirlo en el celular necesitas una app que lo entienda: con Jaguar Code se abre desde el Taller y se ejecuta al momento.

En esta guía

  2. Pasos para abrirlo en Android
  3. Cómo guardar tu programa como .psc
  4. Si el archivo no abre bien
  5. Preguntas frecuentes

Qué es un archivo .psc

Un .psc es un archivo de texto que guarda un algoritmo escrito en pseudocódigo, por ejemplo el de un promedio o el de una tabla de multiplicar. Varias herramientas de pseudocódigo en español lo usan, así que sirve para pasar un programa de un aparato a otro. Si lo abres con un editor de texto, lo ves como cualquier texto; para ejecutarlo hace falta una app de pseudocódigo.

Pasos para abrirlo en Android

  1. Consigue el archivo en el celular. Descárgalo de tu correo, de WhatsApp o de Google Drive. Si lo tienes en la computadora, mándatelo a ti mismo.
  2. Abre Jaguar Code. Instálala en Android o ábrela desde el navegador en app.jaguarcode.org.
  3. Entra al Taller y toca los tres puntos de arriba a la derecha.
  4. Elige «Abrir archivo (.psc)» y selecciona el archivo.
  5. Toca Ejecutar. La consola te muestra lo que hace el programa y te pide los datos que haga falta.

El programa se guarda en tu Taller: puedes cambiarlo y volver a ejecutarlo cuando quieras, aunque no tengas internet.

Cómo guardar tu programa como .psc

Para entregar o llevar tu trabajo a otra computadora, en el mismo menú de los tres puntos elige Guardar como archivo (.psc). Si quieres todos tus programas a la vez, el Taller tiene Guardar todos mis programas, que arma un solo archivo comprimido con un .psc por programa.

Si el archivo no abre bien

  • Las letras con acento salen raras. Pasa cuando el archivo se guardó con otra codificación de texto. Jaguar Code intenta leerlo bien, pero si falla, vuelve a guardarlo en la herramienta original como texto con acentos.
  • Aparece un error en una línea. El programa usa algo que Jaguar Code no entiende. El mensaje dice la línea y una sugerencia; cambia esa instrucción por una equivalente.
  • El archivo es muy largo. Funciona, pero conviene revisar primero que ejecute con datos pequeños.

Prueba con este programa, que puedes copiar a un archivo de texto y guardar como promedio.psc:

Algoritmo suma
    Leer a, b
    Escribir "Suma: ", a + b
FinAlgoritmo

Preguntas frecuentes

¿Qué app abre archivos .psc en Android?

Jaguar Code abre y guarda archivos .psc en Android y en el navegador. Es gratis, no pide cuenta y funciona sin internet.

¿Necesito internet para abrir un .psc?

No. Una vez que tienes el archivo en el celular, abrirlo, ejecutarlo y guardarlo funciona sin conexión.

¿Puedo convertir un .psc a otro formato?

Jaguar Code muestra tu programa como diagrama de flujo, como bloques y, si activas esa vista, traducido a Python. El diagrama se puede guardar como imagen.

Practica esto en Jaguar Code

Escribe pseudocódigo, mira su diagrama y haz la prueba de escritorio desde el celular. Gratis, sin anuncios y sin cuenta.

Abrir la app

Versión de prueba. Puede tener errores y cambiar. Tus programas se guardan solo en tu dispositivo.
