PSeInt en el celular: cómo programar pseudocódigo en Android

PSeInt es un programa de escritorio para Windows, macOS y Linux. Si tu práctica la haces desde el celular, necesitas una app que corra pseudocódigo en Android o en el navegador, y que abra tus archivos .psc.

Qué es PSeInt y dónde se instala

PSeInt es un programa gratuito y de código abierto para aprender a programar con pseudocódigo en español. Se descarga de su sitio oficial y se instala en computadoras con Windows, macOS o Linux. Muchas escuelas lo usan en la materia de lógica de programación.

Su archivo de trabajo es el .psc: un texto con el algoritmo. Ese formato es el que otras herramientas pueden abrir y guardar.

Si solo tienes celular

Para muchos estudiantes el celular es el único aparato propio: la computadora es de la sala de cómputo o de la familia. Si la tarea es un algoritmo, lo que necesitas es una aplicación que corra pseudocódigo en el celular, ya sea instalada en Android o abierta desde el navegador.

No toda app de pseudocódigo sirve igual. Antes de elegir una, revisa estos puntos.

Jaguar Code como opción para el celular

Jaguar Code es una app gratuita para aprender lógica de programación que cumple esa lista: escribes pseudocódigo en español, lo ejecutas y ves la consola; abre y guarda archivos .psc; funciona sin internet, no pide cuenta ni muestra anuncios, y es software libre con licencia AGPL. Se instala en Android o se abre en el navegador, y también corre en la computadora.

Además del código, trae el diagrama de flujo de tu programa, una vista de bloques, la prueba de escritorio hecha sola, doce retos con pistas y lecciones cortas. Los errores salen en español, con la línea y una sugerencia.

Este es un ejemplo sencillo, como los que se hacen en clase:

Algoritmo promedio
    Escribir "Primera calificación:"
    Leer a
    Escribir "Segunda calificación:"
    Leer b
    p <- (a + b) / 2
    Escribir "Promedio: ", p
FinAlgoritmo

Jaguar Code es un proyecto independiente: no es PSeInt ni está afiliado a él. Lo mencionamos porque el pseudocódigo básico que se enseña con PSeInt es el mismo que Jaguar Code entiende.

Cómo llevar tus programas al celular

  1. En la computadora, guarda tu algoritmo como archivo .psc.
  2. Mándatelo por correo, WhatsApp o Google Drive.
  3. En el celular, abre Jaguar Code, entra al Taller y elige Abrir archivo (.psc).
  4. Toca Ejecutar y revisa la consola.

Jaguar Code entiende el pseudocódigo básico (variables, decisiones, ciclos, arreglos y funciones). Si un programa usa algo muy particular de otra herramienta, la app te dice en qué línea no lo entendió. Más detalles en la guía para abrir archivos .psc en Android.

Preguntas frecuentes

¿En qué dispositivos se instala PSeInt?

Su sitio oficial ofrece descargas para computadoras con Windows, macOS y Linux. En el celular se usan otras aplicaciones de pseudocódigo.

¿Puedo abrir en Jaguar Code los archivos .psc que hice en la computadora?

Sí. Jaguar Code abre y guarda archivos .psc. Entiende el pseudocódigo básico; si algo no lo entiende, te dice la línea.

¿Jaguar Code es gratis y necesita cuenta?

Es gratis, no tiene anuncios, no pide cuenta para usarse y es software libre con licencia AGPL.

¿Funciona sin internet?

Sí. Escribir, ejecutar, ver el diagrama y hacer la prueba de escritorio funcionan sin conexión. Solo las clases en línea necesitan internet.
