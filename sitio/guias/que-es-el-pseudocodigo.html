Qué es el pseudocódigo

El pseudocódigo es una forma de escribir un algoritmo con palabras parecidas a las de un lenguaje de programación, pero sin reglas estrictas de sintaxis. Sirve para pensar la solución antes de programar.

Para qué sirve

Programar directamente obliga a pensar en la solución y en las reglas del lenguaje al mismo tiempo. El pseudocódigo separa las dos cosas: primero decides qué hacer y después lo traduces a Python, C, Java o el lenguaje que uses.

No hay un pseudocódigo oficial; cada escuela usa pequeñas variaciones. Lo importante es que se lea con claridad y que cada paso sea preciso. En esta guía se usa el estilo que se enseña en las materias de lógica de programación, con palabras en español.

La estructura de un programa

Un programa empieza con Algoritmo y un nombre, y termina con FinAlgoritmo. Entre los dos van las instrucciones, una por línea y de arriba hacia abajo. Las que están dentro de un Si o de un ciclo se escriben con sangría (unos espacios a la izquierda) para ver dónde empiezan y terminan.

Algoritmo saludo
    Escribir "¿Cómo te llamas?"
    Leer nombre
    Escribir "Hola, ", nombre
FinAlgoritmo

Escribir muestra algo en pantalla. Leer pide un dato y lo guarda en una variable: una caja con nombre donde se guarda un valor.

Ejemplo: tomar una decisión

Este programa lee una calificación y dice si se aprobó. La flecha <- guarda un valor; el Si compara.

Algoritmo aprobado
    Leer calificacion
    Si calificacion >= 6 Entonces
        Escribir "Aprobado"
    SiNo
        Escribir "Reprobado"
    FinSi
FinAlgoritmo

Ejemplo: repetir pasos

Cuando sabes cuántas veces repetir algo se usa Para. Este programa muestra la tabla del 5:

Algoritmo tabla_del_5
    Para i <- 1 Hasta 5 Hacer
        Escribir "5 x ", i, " = ", 5 * i
    FinPara
FinAlgoritmo

Y cuando no sabes cuántas veces, se usa Mientras: este suma números hasta que escribas 0.

Algoritmo suma_hasta_cero
    suma <- 0
    Leer n
    Mientras n <> 0 Hacer
        suma <- suma + n
        Leer n
    FinMientras
    Escribir "Total: ", suma
FinAlgoritmo

Variables y tipos de datos

Una variable guarda un dato, y cada dato tiene un tipo: un entero (7), un real (3.5), un texto ("hola") o un lógico (verdadero o falso). Para unir un texto con un valor se usa + o una coma dentro de Escribir.

Algoritmo precio
    Leer precio
    total <- precio * 1.16
    Escribir "Total con IVA: " + total
FinAlgoritmo

Del pseudocódigo a otros lenguajes

Una vez que el algoritmo funciona, traducirlo es casi mecánico. Por ejemplo, la decisión de las calificaciones en Python:

calificacion = float(input())
if calificacion >= 6:
    print("Aprobado")
else:
    print("Reprobado")

Cambian las palabras (Si por if, Escribir por print), pero la idea es la misma. Por eso conviene dominar primero la lógica.

Errores comunes

  • Olvidar el cierre: cada Si necesita su FinSi, y cada Mientras su FinMientras.
  • Usar una variable sin darle valor: hay que leerla o asignarla antes.
  • Confundir = con <-: la flecha guarda un valor; el igual compara.
  • Un ciclo que no termina: si dentro del Mientras nada cambia la condición, se repite para siempre.

Preguntas frecuentes

¿Existe un pseudocódigo oficial?

No. No hay un estándar: cada libro y cada escuela usa su estilo. Si lo escribes con claridad y con pasos precisos, cualquiera lo puede seguir.

¿El pseudocódigo se puede ejecutar?

Escrito en papel, no. Pero con un programa que lo entienda, como Jaguar, lo ejecutas y ves el resultado, y también puedes ver su diagrama de flujo.

¿Es mejor empezar por pseudocódigo o por Python?

Depende de quién lo enseñe, pero empezar por pseudocódigo permite concentrarte en la lógica sin pelear con la sintaxis. Después el paso a Python, C o Java es más corto.
